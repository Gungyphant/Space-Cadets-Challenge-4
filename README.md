This is my solution to Space Cadets challenge 4, where we must make a client-server communication system

> ▶ a Server program: receives messages and prints them on its local display
> 
> ▶ a Client program: waits for the user to type a message, and then sends it to the Server
> 
> ▶ Extension: Multiple Clients

To activate the server, run server.py (there are optional command-line parameters to name the server and specify a port)

To activate the client, run client.py and enter the IP and port of the server, and the client name. Alternatively, these can be passed in as command-line arguments, either in the form "ip port name" or "ip:port name"
