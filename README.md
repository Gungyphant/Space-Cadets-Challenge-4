This is my solution to Space Cadets challenge 4, where we must make a client-server communication system

> ▶ a Server program: receives messages and prints them on it’s local display
> 
> ▶ a Client program: waits for the user to type a message, and then sends it to the Server
> 
> ▶ Extension: Multiple Clients

To activate the server, run server.py

To activate the client, run client.py and enter the IP and port of the server. Alternatively, these can be passed in as command-line arguments, either in the form "ip port" or "ip:port"
